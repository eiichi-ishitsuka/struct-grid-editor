# ADR 004: YAML パーサーライブラリの選定

## ステータス
承認済み (Accepted)

## コンテキスト
TypeScript/JavaScript エコシステムには複数の YAML パーサーが存在します:
1. `js-yaml`: 最も広く利用されているが、CST（具象構文木）を扱えず、パース時にコメントが完全に消落する。
2. `yaml` (npm: `yaml`): Eemeli Aro 氏による公式仕様準拠のパーサー。CST/AST レベルでコメント、改行、空白を保持・操作可能。TypeScript ネイティブ。

## 決定
**`yaml` (npm パッケージ)** を採用しました。

## 理由
- `parseDocument()` を使用することで、AST を保持したまま値を更新できる。
- YAML 1.2 仕様に完全準拠しており、アンカーやマルチライン文字列のサポートが強固。
- アクティブにメンテナンスされており、VS Code 拡張機能のバンドルサイズへの影響も許容範囲内。
