# コーディング規約 (Coding Conventions)

## 1. 型安全性の徹底
- `any` 型の使用は原則禁止。やむを得ない場合（動的 JSON の境界など）を除き、ジェネリクスまたは適切な Value Object / Union 型を使用すること。
- 引数やプロパティのオプショナル指定時は、`undefined` と `null` の扱いを明確にすること。

## 2. 不変性と純粋関数
- ドメインモデルおよび Value Object の状態変更メソッドは、常に新しいインスタンスを生成して返すこと（Copy-on-write / Immutable パターン）。
- 破壊的メソッド（`Array.prototype.splice`, `push` など）をドメインモデル内で直接露出させないこと。

## 3. テストのルール
- ドメイン層 (`src/domain/`) およびアプリケーション層 (`src/application/`) のコードには、必ず対応する単体テストを `src/test/` 内に記述すること。
- テストは VS Code を起動することなく `npm run test:unit`（Vitest）で 1 秒以内に完了できる状態を維持すること。

## 4. エラーハンドリング
- パースエラーや構文不正は例外を上位に握りつぶさず、ユーザーにわかりやすいメッセージを Webview または VS Code の通知（`showErrorMessage`）で提示すること。
- 不正なパスやインデックスアクセスは、クラッシュさせずに安全にフォールバックすること。

## 5. 絵文字の使用禁止
- すべての成果物（ソースコード、UI、ドキュメント、コミットメッセージ、アーティファクト等）において絵文字の使用を禁止する。
